# Target Output Standard

The Architecture Upload Wizard interactive demo is the reference quality bar for every individual template in this bundle.

## Required presentation

- A named, searchable component resource inside the Component Library.
- A polished interactive demo using safe local mock data.
- A clear component title, product/context label and current demo state.
- Technical-details access and downloadable implementation code.
- Responsive behaviour that still exposes the whole workflow.

## Required behaviour

- Preserve the original component's fields, actions, states, validations, calculations, confirmations and callbacks.
- Make the primary flow genuinely interactive; no decorative/inert controls.
- Provide visible progress, selection, save, error and completion feedback where the source behaviour has it.
- Use local mock adapters so the demo works without the original server.
- Keep API paths and persistence outside the reusable view component.

## Permitted improvement

The UI may be cleaner than the source. Improve hierarchy, spacing, responsive layout, grouping and wording while keeping behaviour and information content intact.

## Evidence in each brief

Every `individual-templates/<id>/` folder contains the exact driver functions, original source line ranges, contracts, local template data and demo scenarios for that one component.
